DOM Y BOM

Cuadro Comparativo

Aspecto DOM (Document Object Model) BOM (Browser Object Model)
Definición Conjunto de funciones y atributos que actúan como una API para manipular documentos HTML, XML y SVG. Permite acceder y modificar la estructura y contenido del documento. Modelo de objetos del navegador que representa la ventana del navegador y sus componentes como historial, ubicación, pantalla y navegador.
Qué controla Controla la estructura y el contenido del documento HTML/XML. Controla el navegador, la ventana, el historial, la ubicación y la pantalla.
Objetos principales
  • document
  • element
  • node
  • document.body
  • document.head
  • window
  • location
  • history
  • navigator
  • screen
Ejemplos de uso Cambiar texto de un elemento: 
document.getElementById("titulo").innerText = "Hola Mundo";
Cambiar color de un elemento: 
document.querySelector("p").style.color = "red";
 Obtener tamaño de la ventana: 
window.innerWidth;
window.innerHeight;
Redirigir a otra página: 
window.location.href = "https://google.com";
Diferencias clave
  • Se enfoca en el contenido y estructura del documento
  • Permite manipular HTML y CSS
  • Depende del documento cargado
  • Objeto principal: document
  • Se enfoca en el navegador y su entorno
  • Permite controlar ventanas, historial y URL
  • Depende del navegador
  • Objeto principal: window
